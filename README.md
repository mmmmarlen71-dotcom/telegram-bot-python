# telegram-bot-python
Простой учебный проект на Python.

## Что реализовано:
- обработка текстовых сообщений
- базовая логика ответа
- пример функции получения данных (погода)

## Как работает:
Запускается в консоли, принимает текст от пользователя и возвращает ответ.

## Технологии:
- Python

Проект выполнен в рамках самостоятельной практики.
